# MelodyGenome
A Genetic Algorithm-based melody generation engine utilizing music theory-driven fitness evaluation.
## 项目文件介绍
**README.md**: 本文件

**main.py**: 遗传算法主要程序

**transform.py**: 将生成的序列转化为音频文件的程序

**generated_music.csv**: 遗传算法程序生成的音乐序列

**dataset_acg_ost.csv**, **dataset_classical_instrumental.csv**, **dataset_pop_contemporary.csv**: 算法使用的数据库

**output_midi**: 生成的音频文件文件夹，内含多个**gen_XX.mid**音频文件
